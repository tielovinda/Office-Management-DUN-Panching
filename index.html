Backup, Restore dan Muat Turun

Backup Semua Data

Simpan satu salinan lengkap semua rekod sebagai fail JSON. Fail ini boleh digunakan untuk memulihkan data pada pelayar lain.

Restore / Pulihkan Data

Pilih fail backup JSON yang pernah dimuat turun. Data semasa akan digantikan dengan data dalam fail backup.

Muat Turun CSV

Muat turun setiap kategori rekod untuk dibuka menggunakan Excel atau Google Sheets.

Pengurusan Data

Padam semua rekod hanya selepas membuat backup. Tindakan ini tidak boleh dibatalkan.
